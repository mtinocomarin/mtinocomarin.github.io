Current research / 2024-Present

Real-Time EMG Classifier System

A standalone STM32 system that recognizes grasp and release intent from forearm muscle activity for real-time robotic control.

  • Implemented surface-EMG acquisition, time-domain feature extraction, and Linear Discriminant Analysis in embedded C.
  • Used ADC with DMA ping-pong buffering, interrupt-driven processing, UART, and hardware timers for deterministic data capture.
  • Verified a 1,000 Hz sampling rate with an oscilloscope and achieved 95-99% accuracy in initial prerecorded-signal testing.
  • STM32
  • Embedded C
  • Surface EMG
  • LDA
  • DMA

Research collaboration / Sequential sensor fusion

REACH ExoGlove Sensor-Fusion System

A multimodal control framework for a powered, four-finger hand exoskeleton that combines edge computer vision, surface EMG, and model-based force estimation to support intuitive grasp-and-release tasks.

  • A Raspberry Pi 5 and IMX500 AI Camera use YOLOv8n object class and distance estimates to select an object-specific grasp profile and initiate closure.
  • Designed and deployed the STM32L476RG EMG module, which extracts MAV, waveform length, zero crossings, and slope-sign changes before applying LDA to classify the user's hold or release intent in real time.
  • An Arduino Mega coordinates four independently actuated, cable-driven fingers while motor-current sensing supports model-based fingertip-force estimation.
  • A sequential state machine assigns control by task phase: vision monitors approach and initiates grasping, the glove maintains the hold, and EMG returns release control to the user.
  • Sequential Sensor Fusion
  • sEMG
  • YOLOv8n
  • STM32L476

Wearable assistive technology

Sense Hat

A wearable spatial-awareness device designed to help people with visual impairments detect surrounding obstacles through 360-degree distance sensing and intuitive vibration feedback.

  • Combined six time-of-flight sensors, eight haptic motors, pressure sensing, and a gyroscope around an STM32L476 controller.
  • Mapped measured distance values to directional PWM vibration feedback and streamed system telemetry over UART.
  • Implemented explicit start, idle, active, and safety-stop states for predictable operation.

Computer vision / 2024-2025

EnviroView Stereo-Vision Scanner

Built a low-cost environmental-mapping proof of concept pairing a Raspberry Pi stereo camera with a stepper-driven rotating chassis. A Python pipeline converts stereo image pairs into disparity maps, depth information, and 3D point clouds.

  • Moved from StereoSGBM to NVIDIA FoundationStereo after real-world vibration and alignment errors limited traditional matching.
  • Implemented repeatable rotating capture sweeps and automated Raspberry Pi-to-PC image transfer.
  • Generated color disparity maps and point clouds; five reported measurements produced approximately 0.33-inch mean absolute error.

  • FoundationStereo

Autonomous robotics / 2026

E.N.G.R. Guidance Robot

Designed and integrated a human-centered indoor guide robot for SFSU's Science and Engineering Innovation Center. The ROS 2 system detects approaching visitors, accepts room or person destinations, and guides users through the building.

  • Integrated YOLOv8n person detection, Cartographer SLAM, and Nav2 path planning and obstacle avoidance.
  • Used RealSense RGB-D, 360-degree LiDAR, wheel odometry, and IMU sensing on a Quanser QBot with onboard NVIDIA computing.
  • Developed LiDAR-filtering and map-labeling tools; in five-person testing, 5/5 felt comfortable interacting and found the path easy to follow.

Edge machine learning / 2024

On-Device Waste Classification

Trained and deployed a lightweight YOLO11n object detector to help identify recyclable material categories on resource-constrained hardware.

  • Trained on 10,000 images spanning biodegradable, glass, metal, cardboard, plastic, and paper categories.
  • Deployed the 2.6-million-parameter model to a Raspberry Pi 4 with a camera.
  • Recorded 0.657 precision and 0.531 recall, including mAP@50 of 0.856 for glass and 0.775 for metal.
