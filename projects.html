Embedded machine learning / 2024—Present

Real-Time LDA EMG System

A standalone STM32 system that recognizes grasp and release intent from forearm muscle activity for real-time robotic control.

  • Implemented surface-EMG acquisition, time-domain feature extraction, and Linear Discriminant Analysis in embedded C.
  • Used ADC with DMA ping-pong buffering, interrupt-driven processing, UART, and hardware timers for deterministic data capture.
  • Verified a 1,000 Hz sampling rate with an oscilloscope and validated ADC, DMA, and serial behavior using an Analog Discovery 2 logic analyzer.
  • Achieved 95–99% accuracy in initial testing with prerecorded EMG signals, with consistent results on both the PC and STM32.
  • STM32
  • Embedded C
  • Surface EMG
  • LDA
  • DMA

Computer vision / 2024—2025

Stereo Vision for 3D Room Modeling

Led software development for a four-person team building an affordable stereo-camera alternative to LiDAR for indoor 3D reconstruction.

  • Built Raspberry Pi software for synchronized stereo capture, 360-degree motorized imaging, and Bluetooth transfer to a host PC.
  • Implemented calibration, rectification, StereoSGBM disparity, depth estimation, and Open3D point-cloud visualization.
  • Moved to NVIDIA FoundationStereo after vibration and real-world imperfections limited traditional stereo matching.
  • Delivered a working capture and point-cloud prototype; identified the 30-minute deep-stereo processing time as the main target for optimization.
  • Python
  • OpenCV
  • Open3D
  • FoundationStereo
  • Raspberry Pi

Research software / Active development

EMG Analysis & Recording Tool

A multithreaded desktop application for synchronized EMG, feature, and video analysis used to study signal behavior and improve labeling strategies.

  • Plots raw EMG alongside MAV, waveform length, zero crossings, and slope-sign-change features in real time.
  • Synchronizes camera recordings with EMG trials and supports action-window labeling, batch processing, and training/testing workflows.
  • Connects Python to C feature-extraction code and STM32 data over UART while managing recordings, logs, and trial files.

  • NumPy

Research software / Team lead

Motor Skill Acquisition Tool

Led a four-person team in replacing a costly, error-prone LabVIEW workflow with an open-source Python application now used by SFSU’s Skill Acquisition and Neuroscience Lab.

  • Automates calibration, pixel-to-metric scaling, Euclidean error measurement, batch processing, and summary statistics.
  • Built a zoomable PyQt5 interface with undo, interactive annotations, scatter plots, and CSV/Excel export.
  • Reduced analysis time from hours to minutes and eliminated the approximately $500 software cost.
  • Delivered on time through weekly client reviews; the tool is actively used for motor-learning experiments.
  • Python
  • PyQt5
  • NumPy
  • Data Analysis
  • Team Leadership
