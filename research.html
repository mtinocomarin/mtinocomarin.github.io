Research

Robotics & Embedded Systems Research

My research combines real-time firmware, sensing, machine learning, computer vision, and robotic control. Some of my current applications are in assistive technology, but my broader focus is robotics.

Active research

Current directions

Embedded classification system

Real-Time LDA EMG System

A standalone embedded system for acquiring surface EMG signals, extracting features, and running an LDA classifier in real time on an ARM Cortex-M microcontroller. Initial prerecorded-signal tests achieved 95–99% accuracy across PC and STM32 deployments; the integrated real-time system currently achieves approximately 90% intent recognition.

  • Surface EMG
  • LDA
  • ARM Cortex-M
  • Real-Time Firmware

Multimodal robotic system

Multimodal ExoGlove

A separate robotic glove platform that uses the EMG classifier alongside computer vision and embedded glove control. The system combines multiple sensing modes to support intention-aware grasping and releasing.

  • Sensor Fusion
  • Computer Vision
  • Embedded Control
  • Robotics

Master's thesis direction

Temporal EMG Classification

Investigating temporal approaches to improve the performance and reliability of EMG movement-intent classification beyond the original LDA-based system.

  • Time-Series Signals
  • Machine Learning
  • Intent Recognition
  • Real-Time Systems
