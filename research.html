Current research / Embedded classification

Real-Time EMG Classifier System

A standalone embedded system for acquiring surface EMG signals, extracting features, and running an LDA classifier in real time on an ARM Cortex-M microcontroller. Initial prerecorded-signal tests achieved 95–99% accuracy across PC and STM32 deployments; the integrated real-time system currently achieves approximately 90% intent recognition.

  • Surface EMG
  • LDA
  • ARM Cortex-M
  • Real-Time Firmware

Research collaboration / Sequential sensor fusion

REACH ExoGlove Sensor-Fusion System

A multimodal controller for a powered hand exoskeleton that assigns complementary roles to each sensing mode: edge vision detects objects, estimates distance, and initiates an object-specific grasp; model-based force estimation monitors interaction; and an STM32-based surface-EMG classifier recognizes hold or release intent so the user controls when the glove opens.

  • Sequential Sensor Fusion
  • Surface EMG
  • YOLOv8n
  • Force Estimation
  • Hand Exoskeleton
