# Milton Tinoco — Engineering & Research Portfolio

Static portfolio website for embedded systems, robotics, machine learning,
computer vision, biomedical engineering, and assistive technology projects.

Built with plain HTML, CSS, and JavaScript for deployment on GitHub Pages at
[mtinocomarin.github.io](https://mtinocomarin.github.io).

## Content

- `index.html` — portfolio homepage and featured work
- `projects.html` — project overview
- `research.html` — research themes
- `experience.html` — experience timeline placeholder
- `about.html` — personal engineering profile
- `assets/` — project images, videos, and resume

Add `Milton-Tinoco-Resume.pdf` to `assets/resume/` to enable the resume link.
